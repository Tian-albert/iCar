# 车记本（iCar）常见问题

## 车记本是什么

车记本是一款记录车辆花费的微信小程序：加油、充电、保养、维修、日常支出五类记录，自动计算油耗、电耗与每公里成本，并提供保养到期提醒。没有会员、没有广告，数据全部保存在用户手机本地。

## 数据存在哪里？会不会丢？

全部保存在微信本地存储（用户手机），不上传服务器、没有账号体系、断网也能用。这意味着卸载小程序、清理微信存储、更换手机都会导致数据丢失，建议定期到「设置 → 数据导入导出」导出备份文件。

## 换手机怎么把数据带过去？

旧手机：设置 → 数据导入导出 → 导出备份文件 → 发送到「文件传输助手」。新手机：登录同一微信 → 下载该文件 → 设置 → 数据导入导出 → 选择备份文件 → 导入。恢复时可选「合并」（保留本机现有数据）或「覆盖」（先清空本机再写入）。

## 删掉的记录还能找回吗？

能。删除只是移入「回收站」，30 天内都可以恢复：设置 → 回收站 → 找到记录 → 恢复。超过 30 天会被自动清理，之后无法恢复。

## 为什么油耗显示「--」？

油耗需要「两次加满」才能计算：本次记录标记为「加满」，且上一次也是「加满」或「油量低」，这两次之间的里程才算有效区间。只记过一次、中间有未加满的记录、或者上次记了但选了「没记」，都会显示「--」。

## 为什么「总里程」和仪表盘不一样？

车记本显示的是「建档后行驶里程」＝ 当前里程 − 购车时填写的里程。这样每公里成本才准确：买车之前跑的路不该算进用户记录的开销里。仪表盘显示的是车辆总里程，两者本来就不同。

## 混动车的油耗和电耗怎么算？

加油记录按升计算油耗（L/100km），充电记录按度计算电耗（kWh/100km），两者分开统计、不会相加。如果填写了 EV / HEV 里程拆分，还能分别看到两种模式各自的里程占比。

## 保养提醒什么时候会亮？

默认剩余里程 ≤ 500 km 或剩余天数 ≤ 15 天时提醒。可以在「车辆详情 → 保养进度 → 设置」里按车调整这两个阈值，也可以在「设置 → 保养到期提醒」整体关闭提醒。超期项显示红色，临近项显示橙色。

## 保养项删光了会自动重建吗？

不会。当前版本删光后不会自动重建（旧版本的问题已修复）。如果想恢复默认保养项，在「保养管理」页点「恢复默认」。

## 收费吗？有会员吗？

完全免费，没有会员、没有内购、没有广告。数据纯本地，也没有服务器成本需要分摊。

## 支持多辆车吗？

支持。在「车辆」页点右上角「＋」添加车辆，每辆车有独立的油耗、电耗、支出统计和保养周期。可以把常用车设为「置顶」，首页的「今年花费」环形图会按车分开显示。

## 支持哪些记录类型？

五类：加油、充电（由车辆能量类型自动决定）、保养、维修、日常支出（停车、高速、保险、洗车等，类别可自定义管理）。

## 怎么生成分享图？

统计页底部点「生成统计图片」，可选三种视觉风格（极简线稿 / 杂志封面 / 深色运动）与两种模式（精简 / 详细），共 6 种组合。生成后可发送给朋友、分享到朋友圈或保存到相册。

## 怎么换皮肤？

设置 → 皮肤，可选「极简线稿」「杂志封面」「深色运动」三套，切换后立即生效，重启小程序会记住选择。

## 导出备份时提示无法保存到手机？

微信限制手机端不能直接把文件写入文件管理器。解决办法是把备份文件发送到「文件传输助手」，长期保存在聊天记录里；在电脑端微信可以另存为本地文件。

## 自定义图标会一起导出吗？

不会。备份包含车辆、加油/充电、保养、维修、支出等全部记录，但自定义图标图片不包含在内，恢复时会换成对应的预设图标。

## 遇到问题怎么反馈？

设置 → 反馈与建议，点击可复制反馈邮箱。反馈时如果能说明操作路径和现象，定位会更快。
