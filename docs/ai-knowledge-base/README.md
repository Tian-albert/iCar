# AI 知识库素材

> **本 README 不要上传**，只上传同目录下的 `车记本常见问题.md`。
> 知识库文件里的每一行都会被检索和引用，所以上传件里不能出现「本文档用于…」这类元信息。

## 上传步骤

1. 微信公众平台 → 基础功能 → AI 能力 → 知识库
2. 上传 `车记本常见问题.md`（支持 PDF / DOC / DOCX / PPT / PPTX / TXT / MD / XLSX，单文件 ≤ 10MB，最多 10 个文件）
3. 等文件状态变「已解析」（通常几分钟）
4. 用平台「调试器 → 调试环境」快速验证切片召回
5. 效果确认后点「发布」，状态变「已发布」才在正式版生效

## 调试器的已知边界（官方文档原文）

- 调试器是**简易效果**：只能验证「文件是否被正确切片召回」
- **非 C 端最终回答效果**，**无上下文**，**无法调用 SKILL**
- 想验证「SKILL + 知识库」的联合效果，只能在**开发版 / 体验版**里测
- 内测期知识库召回只在开发版和体验版开放（正式版需文件已发布）

## 写作口径

- 只讲事实与操作路径，不写营销话术
- 每条答案 3 句以内，第一句直接给结论
- 涉及页面路径时写全（「设置 → 数据导入导出」），方便用户照做
