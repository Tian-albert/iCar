### 1.5 前置审批项（结论：不涉及）

本项目为纯工具型记账应用（记录 + 统计，数据仅存本地），不发布新闻、视听、出版、医疗、金融等内容，无评论/发帖等用户生成内容的公开传播，因此**不涉及任何互联网信息服务前置审批项**，仅需完成 1.1 的 ICP 备案即可。

| 前置审批项 | 本项目是否涉及 |
| --- | --- |
| 新闻 / 出版 / 教育 / 医疗保健 / 药品器械 / 网络文化 / 视听节目 / 金融 / 宗教 / 地图 / 通讯社交 | 均不涉及 |

- [ ] 确认未在后台选择「金融」「医疗」「教育」等**需资质**的类目（此类目会要求提交许可证）
- [ ] 类目选择普通类目（`工具 > 效率` 或 `生活服务 > 汽车服务`），不触发前置审批

> 备案（ICP 备案）与前置审批是两回事：备案是**普通备案**（所有小程序都要做），前置审批是**特定行业**才需要的许可证，本项目只做前者。
>
> 若后续新增「会员付费」（个人主体小程序不支持微信支付）或「用户晒单 / 社区」功能，届时再评估支付资质与内容审核，V1 均不涉及。

## 6. 常见驳回与应对

| 驳回理由 | 原因 | 应对 |
| --- | --- | --- |
| 隐私协议未声明相册/文件权限 | 1.2 未填或与代码不一致 | 补齐隐私指引，声明与 `chooseMedia` / `chooseMessageFile` 对应 |
| 功能无法体验 / 需登录 | 审核员看到空态或误以为要登录 | 备注写明「无需登录、纯本地」，并给体验路径 |
| 类目与实际功能不符 | 选了金融/医疗等类目 | 改为「工具 > 效率」 |
| 页面空白或报错 | 自定义 TabBar 或图表在审核环境异常 | 上传前真机走查；确认 `filterNoDependentFiles: false` |
| 内容涉及违规收集信息 | 声明了未使用的权限 | 只声明实际调用的 3 项 |
| 名称/简介与实际功能不符 | 简介过于笼统 | 简介直接写「记录加油、保养、维修、支出」 |

## 8. 已知限制（建议在简介或 FAQ 中说明）

- 数据**仅存本地**，换手机 / 卸载 / 清缓存会丢失，需用「数据导入导出」备份
- 不支持多端同步（云同步为 V2）
- EV / 混动暂无独立充电流程，充电花费可在「记支出」中记录
- 维修暂不支持上传图片（V2）
