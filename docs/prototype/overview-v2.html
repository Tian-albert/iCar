关键结构变化

  • P0顶部「本年 / 本月 / 全部」分段控件，替代写死的「本年」
  • P0「本月」下出现月份切换器，可翻任意历史月
  • P0每公里成本直接显示算式（合计支出 ÷ 有效里程）
  • P0保养提醒卡右上角「全部 N 项 ›」→ 全车保养页
  • P1全车保养页：按车分组 + 待处理/全部切换 + 进度条
  • P1本周与上月对比（环比），支撑「跟上个月比」类问题

与 AI 接力的对应关系

  • 「今年花了多少」→ 概览（本年）
  • 「上个月 / 某月花了多少」→ 概览（本月 + 指定月份）
  • 「该保养了吗」→ 全车保养（待处理）
  • 「我有几辆车」→ 我的车辆（列表）

刻意不改的

  • 不新增底部 tab，避免挤压现有三栏
  • 保养提醒区块仍在概览内，只是多了「看全部」出口
  • 环图只在所选区间内有支出时渲染，空区间显示空态
