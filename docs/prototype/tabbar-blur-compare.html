FAQ 页 · 无底栏
已按你的要求
二级页不显示底栏。内容可一直滚到屏幕底部，底部留白 20px + 安全区。
常见问题
数据与备份
数据存在哪里？会不会丢？›
全部存在你手机本地，不上传服务器。这意味着：卸载小程序、清理微信存储、换手机，数据都会消失。 建议定期到「数据导入导出」备份一份。
换手机怎么把数据带过去？›
旧手机：「数据导入导出」→ 导出备份文件 → 发给自己的微信文件传输助手。 新手机：下载该文件 → 「数据导入导出」→ 从聊天记录导入。
删掉的记录还能找回吗？›
能，30 天内都可以。删除只是移入「回收站」，到设置 → 回收站里点恢复即可。
油耗与里程
为什么油耗显示「--」？›
油耗需要「两次加满」才能算出：本次加满，且上一次也是加满（或低油量补油）， 两者之间的里程才算有效区间。
为什么「总里程」和仪表盘不一样？›
本 App 显示的是建档后行驶里程 = 当前里程 − 购车时填的里程。 这样每公里成本才准确：买车前跑的路不该算进你记录的开销里。
混动车的油耗和电耗怎么分开算？›
加油记录按升算油耗，充电记录按度算电耗，两者分开统计、不会相加。
保养提醒
保养提醒什么时候才会亮？›
默认剩余里程 ≤ 500 km 或剩余天数 ≤ 15 天时提醒。可在车辆详情 → 保养管理里按车调整。
保养项删了怎么又冒出来了？›
这是旧版本的问题，已修复。现在删光后不会自动重建。

去掉毛玻璃，实际能省多少

backdrop-filter: blur() 是逐帧对底栏背后区域做实时采样 + 高斯模糊。 滚动时这个采样每帧都要重做，是底栏最大的性能开销来源。

场景保留毛玻璃去掉毛玻璃
静止不动无感无感
列表快速滚动 中低端安卓可能出现掉帧 / 边缘撕裂 明显更稳
深色/彩色内容经过 模糊成柔和光晕，观感好 取决于是否透明（见下）

方案 A 和 B 的关键差别

方案 A（半透明无模糊）其实有个隐患：透出的内容是「实心色块」，没有模糊过渡。 这时底栏里的灰色图标与浅灰文字压在彩色块上，对比度会下降， 在最坏情况（浅黄色块）下可能看不太清。

方案 B（完全不透明）没有这个问题：图标与文字永远压在纯白上，对比度恒定。 而且它与页面里的卡片同色（都是 #FFFFFF），视觉上更统一。

我的建议：方案 B（完全不透明）

  • 性能最好：去掉实时采样，滚动更稳
  • 可读性最好：图标文字对比度不受下方内容影响
  • 观感统一：底栏与卡片同色，都是 #FFFFFF
  • 唯一的损失是「玻璃通透感」，但这个 App 是记账工具，不是展示型应用，稳定性比通透感重要

如果觉得纯白太"平"，可以只保留阴影（0 10rpx 30rpx rgba(15,23,42,0.12)） 来维持"浮起来"的感觉 —— 阴影不消耗额外性能。原型方案 B 就是这么做的。
