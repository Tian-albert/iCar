iCar · 更新日志：设置页入口 + 日志页原型

入口放在第三组卡片内、「关于」上方（自助优先组），不新增分组、不动其他行。 日志页用时间轴结构：最新版本置顶加「最新」标签，历史版本依次向下。 每列左「设置页」右「更新日志页」，三套皮肤对照。

设计说明：
· 入口位置：第三组（常见问题 → 反馈与建议 → 更新日志 → 关于）。 「更新日志」本质是产品信息而非操作项，放在帮助组、紧贴「关于」，不混进上面的数据操作组。
· NEW 小标：仅当「存在比用户上次看过的更新的版本」时显示， 首次进入不显示（避免打扰）；点进日志页后清除。
· 数据源：版本列表直接内置在 pages/changelog/index.ts 的常量里（本地优先原则，不拉云端）。新增版本 = 加一个常量对象。
· 文案口径：条目面向用户（说「能干什么」），不写技术细节； 技术细节留在 docs 的 50~53 条。
· 时间轴：最新版本实心主色点 + 「最新」标签；历史版本空心点。 最后一段时间轴线消失，视觉收尾干净。
