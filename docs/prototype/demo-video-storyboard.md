# iCar 车记本 · 演示视频分镜清单

> 成片目标：**60 秒 / 1080×1920 竖屏 / 60fps**
> 口播总量：235 字（按 4.5 字/秒，约 52 秒，留 8 秒呼吸与操作等待）
> 结构：钩子 → 概览 → 联动 → 记账 → 统计 → 分享图（高潮）→ 换肤 → 隐私 → 免费 → CTA

## 一、开拍前置

### 1.1 数据准备（否则画面是空的）

| 项 | 要求 | 为什么 |
|---|---|---|
| 车辆 | 3 辆：主车置顶 + 2 辆普通；至少 1 辆燃油、1 辆纯电 | 环图有 3 段、油耗/电耗文案都能展示 |
| 主车里程 | 当前 5850、购车里程 0 | 「已行驶」与每公里成本数字才合理 |
| 加油记录 | ≥ 4 条，其中**连续两次「加满」** | 否则油耗显示「--」，S4 的卖点就废了 |
| 保养项 | 1 项超期（剩 -100km）、1 项临近（剩 450km）、1 项正常 | S2 需要**一红一橙**对比 |
| 支出记录 | ≥ 8 条，覆盖 4 个分类 | 分类环图 4 段、比例条才有长短差 |
| 主车本年支出 | 必须 > 0 | 概览环图按车分段，无支出则该车无扇区，点了没反应 |

**开拍前清理**：清空通知红点、关掉开发者工具的 Console/Network 面板、退出无关浮窗。

### 1.2 录制参数

| 项 | 设置 |
|---|---|
| 尺寸 | 模拟器 375×812；导出 1080×1920 |
| 帧率 | 60fps（滚动更顺） |
| 触摸指示 | **建议开启**（iOS：设置 → 辅助功能 → 触控 → 辅助触控 → 显示触摸操作；Android：开发者选项 → 显示点按操作） |
| 关闭 | 开发者工具的 FPS / 性能面板、「显示网格」 |

### 1.3 文件命名

`s01a_overview_top.mp4` —— `镜号 + 重录次数 + 简述`，方便剪辑按号拼接。

## 三、录制顺序（省时）

**不要按时间顺序录**，按页面聚拢，一次进页面把该页所有镜头录完：

| 批次 | 镜头 | 进几次页面 |
|---|---|---|
| ① 概览页 | S1（静置）、S2（滚动）、S3（点图例） | 1 次 |
| ② 记账 | S4（分两段） | 1 次 |
| ③ 统计 | S5、S6 | 1 次 |
| ④ 设置 | S7（换肤）、S9（更新日志） | 1 次 |
| ⑤ 导入导出 | S8 | 1 次 |

每条镜头**多录 2 秒头尾**，剪辑时按口播对齐切。

## 四、剪辑要点

1. **转场一律硬切**，禁止叠化、缩放、旋转等花哨转场（数据类内容靠信息而非特效）
2. **每镜开头留 0.3s、结尾留 0.5s 静止**，方便对齐口播
3. **字幕**：底部 1/4 处，距底 120px 安全区，字号约 48px（1080 宽下）
4. **数字对齐**：口播说到「每公里」「8200」时，画面必须正好停在那块
5. **BGM**：轻电子 / lo-fi，音量压到 -22dB，人声 -6dB；S1 和 S10 可抬到 -18dB
6. **节奏**：S4、S6 是高潮可放到 9~10s；S2、S8、S9 可压到 4~5s
