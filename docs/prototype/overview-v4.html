实现说明与待确认

环图交互（点扇区/标签高亮）
原型用 SVG 做的。但小程序 WXML 不支持内联 SVG， 实际要用 canvas 绘制：
· 扇区 + 引出线 + 文字全部 ctx.arc/fillText 画
· 点击命中：bindtap 拿坐标 → 换算成角度与半径判断落在哪个扇区或标签区
· 选中后 setData 重绘（其他扇区降低透明度、中心文字换成该车金额）
这些都能做，但要注意点击重绘会有一次 canvas 重画， 数据量大时建议加个 requestAnimationFrame 节流。
环图布局为什么变了
加了引出标签后，标签要占左右两侧各约 60px， 所以环图做成居中、标签分列两侧（占据整个卡片宽度）， 标签多时按纵向防重叠自动错开。
