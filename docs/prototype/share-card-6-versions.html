分享图 · 3 种风格 × 详细 / 简略 = 6 版

同一份数据、同一套信息结构，只换「视觉语言」。详细版含三组指标卡 + 分类环形图 + 趋势/行程/费用三图； 简略版只留一行三格 + 分类环形图，一屏看完。

与车相关的图形元素

不再画整车，改用几何感更强的汽车符号。点任意一个即可替换下方 A 风格里的装饰图形，直接看实际效果。
① 速度表 — 半圆刻度 + 指针，最贴「数据/里程/油耗」
② 方向盘 — 一眼就是车，几何最干净
③ 公路 — 透视消失点 + 虚线，呼应「记录每一公里」
已用于下方 A 风格
④ 轮毂 — 同心圆，最抽象、最像徽标
选择建议：
· A 极简线稿：最轻、最像「手账/杂志内页」，白底克制；缺点是信息流里抓眼度一般。
· B 杂志封面：暖米白纸感 + 超大字重，高级感和辨识度平衡最好，推荐作主方案。
· C 深色运动：最抓眼、最贴汽车品类，但和 App 浅色基调反差大，适合偶尔发。

落地成本：A / B 全是矩形 + 文字 + 线条 + 贝塞尔，Canvas 零障碍；C 的斜切光带用 path 也能画， 但要处理圆角裁剪与抗锯齿，成本略高。
两种模式的取舍：详细版给「想认真看数据」的人（车友群、自存）；简略版给「朋友圈 3 秒扫一眼」的人， 核心是「花了多少 / 跑了多少 / 钱花在哪」。
