两版定位差异：
  • 详细版（full）：给「想认真看数据的人」，自用存档、发车友群都行；长图，信息全。
  • 简略版（brief）：给「朋友圈 3 秒扫一眼的人」，只留「花了多少钱、跑了多少公里、钱花在哪」；短图，冲击力强。
简略版取舍说明：
  • 指标从「里程 3 列 + 油耗 3 列 + 支出 3 列」压缩为一行三格：增加总里程 / 平均油耗 / 每公里支出——与头部「总支出」互补，不重复。
  • 省去能耗趋势 / 行程 / 费用三张图表（它们信息密度低，3 秒场景看不完）。
  • 分类比例条保留——「钱花在哪」是简略版的核心信息，不能省。
落地提醒：简略版的「一行三格指标」与现有 brief 模式（全部指标卡组）不同，落地时需要给 brief 模式单独的指标子集；纯电车的「平均油耗」会替换为「平均电耗」，与页面口径一致。
