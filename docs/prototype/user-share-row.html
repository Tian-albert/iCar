原因：`.share-btn` 是 <button> 元素，微信给它注入了内置默认样式：
  • text-align: center → 文字居中
  • font-weight: bold → 加粗
  • display: block → 我设的 display: flex 可能不生效
这些内置样式优先级高于普通 class，所以只靠 class 覆盖并不可靠。

做法：button 只当「分享触发器」的壳，布局全部交给内层 view。
  • button 上重置：font-weight: normal、text-align: left、display: block
  • 内层 .share-inner 用 flex + space-between → 箭头自然到最右
  • 内层 padding: 0 16px + button 负 margin，抵消 .card 内边距，文字与「关于」左边缘对齐
这样不受 button 内置样式干扰，与普通 row 视觉完全一致。
