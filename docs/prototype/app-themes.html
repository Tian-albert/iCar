iCar · 三套皮肤

同一套界面结构，只换令牌。每列自上而下：概览 / 统计 / 设置。 A、B 保留品牌蓝作为数据强调色（图表、进度条），避免换肤后丢掉识别度。
落地成本评估：
✔ 低——项目 `app.wxss` 的令牌很完整，除 `custom-tab-bar/index.wxss` 外几乎没有硬编码色值， 换肤本质是换一组变量值。
⚠ 需额外处理的三处：
1. 底栏图标：base64 SVG 里的 `#6B7486` / `#3B6FF6` 是写死的，换肤不会变，需要按主题生成三套图标（或改成运行时可着色的方案）；
2. 图表主题：`utils/chart-draw.ts` 的 `CHART_THEME` 是常量，Canvas 不读 CSS 变量，需要改成按主题注入；
3. 深色对比度：C 主题下 `--color-danger #F5474F`、`--color-warning #E8912A` 对比度下降，已演示为提亮后的 `#FF7B81` / `#FFB35C`。

建议：A（极简线稿）与 B（杂志封面）互斥性不强，可作为「浅色主题包」做成一个开关； C（深色运动）工作量约等于前两者之和，建议单独作为「深色主题」后期再加。
