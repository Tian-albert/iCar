关于「加大透明度」——需要先确认方向

你说「毛玻璃效果不明显，实际实现可能需要加大透明度」，这句话有两种相反的解读：

解读做法效果
A. 让底栏更"实" 不透明度从 0.62 提到 0.88~0.96 底栏更接近白色，下方内容几乎看不见，图标文字更清晰
B. 让底栏更"透" 不透明度从 0.62 降到 0.40~0.50 底栏更透明，下方彩色内容更明显，但图标文字对比度下降

我理解你的意思是 A：因为去掉毛玻璃后，半透明会让下方色块"硬生生穿过来"， 反而显得脏、且图标看不清 —— 所以要提高不透明度把内容压住。 原型里做了 0.62 / 0.78 / 0.88 / 0.96 四档，你可以直接对比。

如果你想要的是 B（更透），告诉我，我另做一版降到 0.40 的对比。

齿轮设计说明

现有三个图标都是：viewBox 24×24、stroke-width 1.7、 stroke-linecap/linejoin: round、描边态 #6B7486、选中态实心 #3B6FF6。 齿轮必须完全对齐这套参数，否则会"一看就是另一套图标"。

参数取值为什么
齿数8（推荐）6 齿在大尺寸下好看，但缩到 23px 会显得"少牙"；10 齿会糊成一圈
齿顶半径9.3留边 2.7，与其他图标的视觉重量一致
齿根半径6.7齿高 2.6，是 23px 下仍能分辨的最小值
中心孔3.4太小（2.4）在描边态下会被描边吃掉，看起来像实心
齿顶圆弧直线会让齿轮显得"凶"，圆弧更符合现有图标的圆润风格

还需要你确认

  • 齿轮选哪个：A（8 齿标准）/ B（6 齿圆润）/ C（6 齿小孔）/ D（8 齿厚齿）？我推荐 A
  • 透明度选哪档：0.62（现状）/ 0.78 / 0.88 / 0.96？我推荐 0.88
  • 图标 key 名：现在是 user，改成 gear 还是保留 user？
    保留 user 的好处是改动最小；但语义上叫 gear 更准确（毕竟不再是"用户"了）。
