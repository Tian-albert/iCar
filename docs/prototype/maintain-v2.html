改动点

  • 概览保养区块：红橙灰三色状态环图 + 图例行（超期 1 / 临期 2 / 正常 3）
  • 概览「管理保养项」→「更多保养项 ›」，进新页
  • 新页全车保养：待处理 / 全部 两个筛选片，按车分组

  • AIqueryMaintain 的全车接力落点改到这一页（比概览锚点更精准）

环图数据从哪来

  • 沿用 buildOverview 已算好的每项 level（overdue / urgent / ok）
  • 环图三段 = 三种 level 的项数占比；中心数字「超期 N / 全部 M」
  • 全为正常时环是整圈灰，中心「0 / M」——不再是空区块
