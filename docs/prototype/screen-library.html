供渲染视频、撰写小红书博文等宣传工作直接取用。所有页面均按真实 WXML/WXSS 还原（rpx ÷ 2）， 尺寸 375×812（iPhone X 逻辑像素），实际截图导出建议 750×1624 @2x。默认皮肤为「极简线稿」， 另两套皮肤（杂志封面 / 深色运动）见 app-themes-v2.html。

② 截图前检查隐私：车牌、真实姓名、精确金额如不想公开，请先改成示例值。
③ 每个界面都给了 定位 / 元素清单 / 录制建议 / 可引用话术 四段，话术可直接改写成文案。
核心卖点对照（写文案时可直接引用）：
· 无会员、无广告、纯本地：数据只存手机，不联网上传（关于页、隐私政策可佐证）
· 每公里成本：自动把油费/电费/保养/维修/支出折算成「元/km」，这是记账类工具里少见的视角
· 保养提醒：剩余里程/天数双阈值，超期标红、临近标橙
· 多车管理：每车独立油耗、成本、保养周期，首页环图对比
· 三套皮肤：极简线稿 / 杂志封面 / 深色运动
· 可导出备份：换机不丢数据，导出文件可长期保存
